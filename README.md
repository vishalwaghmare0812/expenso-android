# 💰 Expenso

A minimal and modern offline-first expense tracker for Android.

## 📱 About

Expenso is an offline expense tracker that helps users manage daily, monthly, and yearly finances with local data storage using Realm Database.

## ✨ Features

- Add and manage income & expenses
- Track finances by day, month, and year
- Add notes to transactions
- Organize transactions with categories
- Automatic date selection
- Indian Rupee (INR) support
- Light & dark theme based on device settings
- Fully offline experience
- No login or sign up required

## 🛠 Tech Stack

- Java 17
- XML
- Android SDK
- MVVM Architecture
- Realm Database
- View Binding
- Material Components

## 🚀 Future Improvements

- Charts & analytics
- Cloud sync and backup
- PDF/CSV export
- Search and filters
- Multi-currency support

## 💾 Storage

Expenso uses Realm Database for local storage.

Benefits:
- No internet required
- Better privacy
- No account needed
